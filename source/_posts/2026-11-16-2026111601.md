## DaVinci Resolve で文字詰めをする方法（基本）


動画編集をしていてタイトルやテロップなどを入れる際に、ただテキストを入れただけだとベタ組みになってしまうので、違和感なく読めるように文字間を調整したい場面というのは多々あると思います。DaVinci Resolve の場合、おそらくみなさん次のような手順でやってらっしゃることでしょう。Web 検索で引っかかる多くの記事で紹介されている内容ではありますが、あらためて書いておきます。

- <b class="keyword">Text+</b> を使用してタイトルやテロップを入れる
- Edit ページでビューワの左下にあるメニューから <b class="keyword">Fusion オーバーレイ</b>を表示
- テキストクリップを選択し、ビューワ上でダブルクリックもしくは範囲を選択してカーソルを表示
- カーソルを文字間調整したい箇所へと移動し、<kbd>alt</kbd> (Windows) または <kbd>option</kbd> (macOS) キー + 左右カーソルキーで調整
  - その際 <kbd>shift</kbd> キーを併用することで大きなジャンプ幅で調整できる
  - また <kbd>ctrl</kbd> (Windows) または <kbd>command</kbd> (macOS) キーを併用することで微調整できる

この方法で詰められるようになったのは割と最近（v19から）のことなので、それ以前のブログ記事などでは違う手順が書いてあるかもしれませんが、Text+ を使うことと Fusion の機能を使用する点は一緒だと思います。


## もっとまとめていい感じに整えられないものか…


ただし、この方法はひとつひとつの文字間を個別に調整するためのもので、テキスト全体をまとめていい感じに文字詰めするようなものではありません。全体を*等しく*詰めたり広げたりするのはトラッキングでできますが、これは CSS でいうところの `letter-spacing` プロパティのようなものですから、ここで求めているものとはちょっと違います。

要するに Photoshop や Illustrator でいうところの「メトリクス」「オプティカル」といった、カーニングの自動調整機能に相当するものが欲しい訳ですが、Text+ クリップのインスペクタを見渡してみても、それっぽい項目は見当たりません…

僕は長いこと基本静止画のデザインしか扱ってこなかったので、プロ向けのアプリならそんなのはできて当たり前だと思っていたところがありまして😅 それっぽい設定項目がパッと見なさそうな時点でかなりショックを受けたのですが、どうやら Premiere Pro にもないらしい[^1]ので、動画編集アプリでは普通なんですかね。知らんけど。

## Text+ には OpenType 機能を有効化できる設定が隠されている


という訳で、あらためて Text+ のインスペクタを見てみましょう。最下部に<b class="keyword">アドバンスコントロール</b>という項目があり、通常は閉じられているのですが、その右矢印部分をクリックして開きます。

![Text+ のインスペクタにて、アドバンスコントロールを開いたところ。読み取り方向、等幅を強制、フォント指定のカーニングを使用、合字を使用、フォント機能といった設定項目、および手動カーニングと手動位置調整をリセットするためのボタンが出現する](/images/2026/11/15/davinci-kerning-panel_open.webp){: width="420" height="330"}

<b class="keyword">フォント機能</b>というラベルの横にテキストを入力できるボックスが見えますが、**ここに4文字の英数字からなる OpenType の機能タグを入力することで、指定した OpenType 機能を有効にできる**ようになってるんですね。

<b class="keyword">OpenType 機能</b>というのはフォントベンダーがフォントにあらかじめ仕込んでいる隠し機能のようなもので、対応アプリを使うことで例えば複雑な合字を有効にしたり、特定の文字の形状を変更したりといったようなことができます。どのような機能があるかは多すぎて書き切れないので、[Adobe Fonts のヘルプ内にある記事][help]などを参考にしてください。

[help]: https://helpx.adobe.com/jp/fonts/web/language-support-and-opentype-features/open-type-syntax.html

そして、多くの日本語 OpenType フォントには `pwid` や `palt`, `pkna` といった、かな文字や約物をプロポーショナルな字形に置き換えたり、相当する字幅に調整したりする OpenType 機能が準備されています（対応度はフォントによって異なります）。つまり、**対応フォントにこのいずれかを指定すれば、テキストクリップ内のすべての文字を一気にプロポーショナル詰めにできる**という訳です。

実際にやってみましょう。まずはタイムラインに Text+ をドロップしてテキストクリップを作成、テキスト欄に適当に文字を入力します。フォントはヒラギノ角ゴシック W6 を使用しました。

![ここでは「ひらがなカタカナ漢字が入り混じったテキスト＋あと数字。 1/2 0345」とした](/images/2026/11/15/davinci-kerning-example_text.webp){: width="578" height="320" }

そしてインスペクタのフォント機能を入力するボックスに、先ほどのいずれかの機能タグを入力します。ヒラギノ角ゴシック W6 はどれを指定しても有効ですが、とりあえずここでは `palt` を入れてみます。

![](/images/2026/11/15/davinci-kerning-panel_palt.webp){: width="420" height="330" }

そして、先ほどのテキストクリップがどのようになったかを確認します。「ト」の左右や句点の後のスペースあたりが元のものより顕著に詰められていることなどから、プロポーショナル詰めが機能していることが分かります。やったぜ。涙

![](/images/2026/11/15/davinci-kerning-example_palt.webp){: width="578" height="320" }


### 文字詰め以外にも使えます（機能タグを複数指定する方法）

ちなみに、プロポーショナル詰めと同時に他の OpenType 機能を指定することもできます。この場合は複数の機能タグをカンマ区切りで入力します。そうです、CSS の `font-feature-settings` プロパティを指定するのと同じ書式ですね。試しにフォントはヒラギノ角ゴシックのまま、こんな指定をしてみました。

![今度は `pwid, afrc, zero` を指定した](/images/2026/11/15/davinci-kerning-panel_3tags.webp){: width="420" height="330" }

再びテキストクリップの表示を確認します。すると…

![「＋」の文字や数字、句点の部分に差違が出た](/images/2026/11/15/davinci-kerning-example_3tags.webp){: width="578" height="320" }

`palt` 指定のみの場合と比較すると、次のような違いがあることが分かります。

- `pwid` にしたので全角の `＋` が英数文字の `+` に置き換えられた
- 句点は `pwid` で置き換え可能なグリフがないため字間は通常のまま
- `afrc` が適用されて `1/2` が二階建ての分数になった
- `zero` が適用されて `0123` のゼロがスラッシュ付きに置き換えられた

OpenType 機能を使うと、このように文字詰め以外にも色々なタイポグラフィ機能を利用できます。フォントを変更しながら色々な機能タグを指定してみると「ああ、このフォントはこんな機能をサポートしてるのか」と新たな発見があるかと思いますので、余裕のある時に試してみるのもいいかもしれませんね。


## この方法の問題点（全フォントで有効にできる訳ではない）


何か問題点があるとすれば、当然ながら**使用したいフォントが OpenType フォントであり `palt`・`pwid`・`pkna` あたりの OpenType 機能をサポートしていることが条件となる**{: .sad }ことですかね。ネットに転がっているフリーのフォントなどは対応してないものも多いと思うので、そういったフォントについては個別に一文字ずつ詰めるしかないです。

また、これらはあくまでもフォントベンダーが文字ごとに指定した設定値を機械的に適用しているだけなので、**使用するフォントやテキストの内容によっては詰めが不十分な箇所が発生することもあります**{: .sad }。基本的には文字詰めの*ベース*として使用するものであり、気になるところは個別に詰めるなどして対応する必要があるでしょう。

とはいえ、おおむね気にならないように詰めてくれるのは確かですし、**すべての箇所をいちいち調整するよりかは、はるかに早く作業を終わらせることができるはずです**。使用しない手はないので、どんどん活用していきましょう。


## まとめ: DaVinci Resolve で文字詰めする方法（完全版?）


最後に、今回紹介した手法と他の既存の調整機能を組み合わせて、DaVinci Resolve でタイトルなどの文字詰めを行う場合のポイントとその手順を考えてみました。次のような感じでどうでしょう?

- フォントは極力 **OpenType フォント**を使用
- タイトルやテロップを入れるツールは **Text+** 一択
- 最初に**フォント機能**に `palt` などを指定してプロポーショナル詰め
- 全体的な字間の具合を**トラッキング**で調整
- 最後に気になる部分を **Fusion オーバーレイ**で微調整

最後の2つはもしかすると逆の方がいいかもしれないのですが、とりあえずのご提案…ということでそのまま置いておきます。よろしければご意見ください。
