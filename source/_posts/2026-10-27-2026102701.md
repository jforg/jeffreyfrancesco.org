## macOS Safari で自動入力可能なフィールドに出てくるアイコン

というのがあります。こんなやつです👇

![例：個人情報の入力欄にフォーカスが当たると、円に囲われた人型アイコンの右横に、開閉可能なことを示す下向き矢印の付いた画像が表示される。スクリーンリーダーなどでは「連絡先情報を自動入力」と読み上げられる](/images/2026/10/27/webkit-contacts-auto-fill-button-light.webp){: width="384" height="208" }
{: .post_thumbnail }

このアイコン[^1]が出てくる入力フィールドには、登録してある自分の連絡先情報などから項目を引っぱってきて、手入力することなく自動で埋められますよ、というサインみたいなものですね。もちろん、実際にそのデータを使って項目を埋めるかどうかは個人の自由です。僕は便利なのでけっこう使っちゃいますが。

[^1]: `::-webkit-contacts-auto-fill-button`という擬似要素、なので正確にはボタンらしい


## ダークモードになると消える…

ですがこのアイコン、ひとつ問題がありまして、**ダークモードが適用されているページで入力フィールドも暗い背景色になっている場合、アイコンが消えてしまう**{: .sad }のです。正確には消えるというより見えなくなります。

![Email 入力欄にフォーカスが当たり、複数あるメールアドレスの選択肢が一覧で表示されているが、アイコンは黒地に黒い塗りつぶしで描かれるため認識できない](/images/2026/10/27/webkit-contacts-auto-fill-button-dark.webp){: width="384" height="208" }
{: .post_thumbnail }

これは Email 入力欄なので、複数のメールアドレスを所有する人はこうやって一覧が表示されますから、まだ「ああ、ここから選択すればいいんだな」と分かりそうですが、その上の Name 欄など何の一覧も出てこない（普通何種類も名前がある人なんていないからね）ので、これでは存在にすら気が付かない人も多いんじゃないでしょうかね。


## なぜ見えなくなるのか

なぜこのようなことになるかといいますと、このアイコンは塗りつぶされたボックスを `mask-image` プロパティでマスクすることで描かれているのですが、**その塗りつぶし色が黒で決め打ちされているため**です。

```css
input::-webkit-contacts-auto-fill-button {
  mask-image: url("data:image/svg+xml,<svg viewBox=\"0 0 44 24\" xmlns=\"http://www.w3.org/200…9 7.2 7.9647 9.5765 C 7.9765 12.1059 9.7412 13.9882 12 14.0118 Z\"/></svg>");
  mask-size: 22px 12px;
  width: 22px;
  height: 12px;
  margin-inline-start: 3px;
  margin-inline-end: 2px;
  background-color: black; /* ← 犯人はお前やぁあああっ! 涙 */
  flex-grow: 0;
  flex-shrink: 0;
  flex-basis: auto;
  -webkit-user-select: none;
}
```

`currentColor` や `canvasText` などにすらなってないということは、ダークモードなどが存在してなかった頃に作成したスタイルから手が入れられてないんですかね。知らんけど。

## 仕方がないので自力で対処した

と、色々思うところはありますが、とりあえずアップルが修正する気がないのであれば、あとはもう自力で対処するしかありません。幸い macOS Safari には（いまどき珍しく）任意のユーザースタイルシートを指定する機能がデフォルトで備わっていますので、それを利用しましょう。テキストエディタを開いて次のようなスタイルを書き、適当なファイル名.css で保存します。

```css
::-webkit-contacts-auto-fill-button:not(:hover, :active) {
  background-color: currentColor;
}
```

このアイコンはマウスホバー時とアクティブ（押し込まれている）時には青色になり、少なくとも判別可能にはなるため `:not()` 擬似クラスで除外しておきます。`canvasText` ではなく `currentColor` 指定なのは、**実際に自動入力で項目が埋まるとテーマに関わらず黄色背景に黒文字になるため、ダークモードの時に白色になる `canvasText` ではまずいのです**。

あとは Safari の設定 > 詳細 > スタイルシートから、保存した CSS ファイルを選択するだけです。

![アップルメニューから（または [command] + [,] キーで）Safari の設定ダイアログを開き、「詳細」タブの「スタイルシート」欄横のプルダウンメニューから「その他…」を選択、開いたダイアログで保存した CSS ファイルを選択する](/images/2026/10/27/webkit-contacts-auto-fill-button-dialog.webp){: width="848" height="608" }

[実際に適用されたものを試せるデモ][demo]（アップルに送信したのと同じものです）を置いておきます。上の `<fieldset>` 内が通常のもの、下が修正コードを適用済みのものです。macOS Safari が使える方で興味のある方は、よろしければ確認どうぞ。それ以外のブラウザの方はそもそも自動入力アイコンが出ないので、見ても意味がないです🤣[^2]

## そんな訳で

macOS Safari で自動入力可能なフィールドに出てくるアイコンがダークモードで見えなくなるのでアップルにフィードバック送ったけど、修正してくれそうになかったので仕方なく自力で対処したわ、というお話でした。

この話は最初 [Zenn] の方に書こうと思ってて、実際途中まで書いていたのだけど、よく考えたらとても限られた環境だけの話だし、その中でも気にしない人は気にしないだろうし、そもそもこんなのは Web 制作者の側で対応するような話でもないよな…と思ったので、考え直してこちらで上げることにした次第です。

という訳で、やり方もとても簡単ですし、気になる人だけが自分で対策することにしておきましょう。
